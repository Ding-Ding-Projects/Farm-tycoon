# Release code names

Each Farm Tycoon release is given a dim sum code name from the public catalog at
https://raw.githubusercontent.com/Ding-Ding-Projects/dim-sum-photos/main/catalog/index.json
A dish is used once per project so a code name never becomes ambiguous between builds.
