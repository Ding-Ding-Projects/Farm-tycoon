Honest status: it plays, and here's exactly what's been checked

The game runs. Every module in the source tree is implemented — the world renders, crops plant and harvest on real timers, buildings craft through the Workshop, and the save file round-trips through localStorage. Loaded in a browser it produces zero console errors and exposes real, mutating game state (coins, diamonds, silo, barn, placed structures) through a debug hook, not a static readout.

npm test runs a content validator plus eight gameplay-logic suites — camera, core economy, logistics, crafting, township, research, dead-time systems, and the social/co-op layer — for 147 passing assertions across nine files, zero failures. All 22 world structures are placed with zero overlaps; twenty of them are locked at level 1 and still present in the world, derelict, and clickable.

There are no gameplay screenshots on this page yet — not because anything is missing, but because a dedicated capture pass hasn't landed. A picture of a placeholder would misrepresent the project either way, so this section stays honest until real captures of the real running game replace it. Two small design/balance questions are also still open — see the repository's HANDOFF.md for the exact numbers behind both.

What's implemented

Every system, built and tested

Each card below describes a system that is implemented and exercised by npm test's gameplay-logic suites — not just data that's been validated for shape. See the status note above for the exact test counts.

The farm loop

Plant crops, raise animals in pens, and harvest on absolute wall-clock timers so progress resolves correctly even after the game has been closed for hours.

22 crops · 12 animals

Buildings are crafted, not bought

Every production building is unlocked through the Building Workshop: gather raw construction materials, craft them into components, assemble a kit, then the finished factory goes up. This construction chain is its own small economy.

26 buildings · 23 materials

A minigame per factory

Fishing, mining, the merge board, expeditions, and foraging are each tied to a specific structure and produce an effect unique to it — bonus yield, rare materials, faster queues. Always an optional bonus layer, never a gate: timers complete on their own whether or not you ever play the minigame, and offline progress is never penalized for skipping it.

3 merge chains

The Township layer

A town of houses and community buildings tracks population against a cap; trains and an airport move finished goods out and construction materials back in; a zoo, a market, and a set of islands round out the second half of the game.

16 houses · 10 community · 14 zoo enclosures · 8 islands

Dead-time systems

Weekend events, mini-events, an annual Farm Fair, and seasonal holidays give the idle time between check-ins something to look forward to, alongside a daily wheel, achievements, and permanent research.

10 weekend events · 6 mini-events · 25 fair tasks · 6 holidays

Simulated neighbours

A request board and co-op systems are designed against simulated neighbour farms rather than a live multiplayer backend, so the social loop works the same offline as it will online.

39 achievements
Under the hood

One module per system

No framework, no bundler, no build step for the game itself. Plain ES modules, DOM for menus, canvas for the world. 37 modules in total (34 in src/, 3 under src/render/), all implemented — this is a sample of the ownership map; see the repository's README.md for the complete list.

What's finished vs. what's still open

Finished and validated

All game content in src/data.js: every crop, animal, building, recipe, good, level, and event. Verified by an automated checker (npm test) that enforces roughly thirty rule families and was deliberately broken and watched fail before being trusted.

Finished and validated

The Windows installer packaging (Squirrel.Windows, unsigned per this project's permanent no-signing policy), the application icon, and the vendored font set used on this page and in the app — all served from this repository, no CDN.

Finished and tested

Every other src/ module — production timers, the renderer, input handling, UI wiring, audio, tutorial, and the full Township/social layer. All 37 modules are implemented and exercised by npm test's eight gameplay-logic suites, 147 passing assertions, 0 failures.

Still open

Gameplay screenshots and recordings — a dedicated capture pass hasn't landed yet — plus two small design/balance questions in the Building Workshop. See the repository's HANDOFF.md and ROADMAP.md for the exact, current list.
